## 📌 Descrição

Este projeto tem como objetivo fazer uma aplicação Multimédia interativa, a promover a **adoção consciente de animais** através de uma aplicação emocional e informativa. Cada animal é apresentado como uma pequena história, com vídeos personalizados, imagens, texto sincronizado e até um modelo 3D interativo com pontos clicáveis.

A experiência foi concebida com base nos princípios de **hipermédia**, **narrativa interativa** e **design centrado no utilizador**, proporcionando uma navegação fluida por conteúdos multimédia ricos e envolventes.

## 📁 Estrutura do Projeto

- `index.html` – página principal da aplicação
- `pets/` – páginas individuais de cada animal
- `videos/` – vídeos personalizados gravados e editados para o projeto
- `photos/` – imagens dos animais e logótipos
- `models/` – modelos 3D utilizados para visualização interativa
- `styles/` – ficheiros CSS
- `scripts/` – ficheiros JavaScript para interatividade e navegação

---

## 🛠️ Tecnologias e Ferramentas

- HTML5, CSS3 e JavaScript
- [Model Viewer](https://modelviewer.dev/) – visualização de modelos 3D
- Clipchamp e Camtasia Studio 8 – edição de vídeo
- Figma e Canva – prototipagem e design visual
- Font Awesome – ícones
- GitHub Pages – alojamento estático da aplicação
